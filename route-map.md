# The Citizen's Record — Multi-Page Route Map

The public site will retain its existing **Evidence Before Opinion** visual system while shifting from one long reading experience to a civic-library model. No source-first content is discarded; it is moved into an appropriate direct route.

| Public route | Purpose | Existing content retained or expanded |
|---|---|---|
| `/` | Start Here | Brand statement, mission, orientation, featured paths |
| `/portals` | Official Portals | Government and institutional source cards |
| `/record` | The Record | Current-information and source-record index |
| `/record/:slug` | Record detail | Source context, original record, inquiry questions, related paths |
| `/resources` | Find Resources | Database-backed searchable resource directory |
| `/resources/:slug` | Resource detail | Persistent published resource and its original source |
| `/toolkit` | Citizen Toolkit | Investigation methods and direct official-research pathways |
| `/toolkit/:slug` | Toolkit detail | A practical field-manual topic and next research steps |
| `/learn` | Learn | Six civic-education guide cards |
| `/learn/:slug` | Guide detail | Guide overview, questions, primary sources, and related pathways |
| `/contact` | Contact | Editorial email, Public Email Policy, correction and privacy guidance |
| `/about` | About | Mission and editorial boundaries |
| `/daily-log` | Daily Log | A transparent publication-status placeholder, without fabricated updates |

The seven primary navigation links are **Start Here, Official Portals, The Record, Find Resources, Toolkit, Learn, and Contact**. They lead to direct routes rather than homepage anchors, and the active route is displayed in the shared header.
